# SocialEvents

A platform for discovering, joining, and creating social events in your community.

[Live Demo](https://socialevents.example.com)

## Features

- **Discover Events**: Browse upcoming social events in your community and beyond
- **Join Communities**: Connect with like-minded people who share your interests
- **Create Events**: Organize your own social gatherings and invite others
- **Event Types**: Filter by types including Cleanup, Plantation, Donation, Awareness, and Relief
- **User Authentication**: Secure email/password and GitHub OAuth authentication with Better Auth
- **Responsive Design**: Fully responsive layout that works on mobile, tablet, and desktop
- **Community Gallery**: Share and view moments from events
- **Newsletter Subscription**: Stay updated with the latest events and community news

## Tech Stack

- **Frontend**: Next.js 16.4.6 with App Router
- **Styling**: Tailwind CSS with custom theming using next-themes
- **Authentication**: Better Auth with MongoDB Adapter
- **UI Components**: lucide-react icons, sonner toaster notifications
- **Database**: MongoDB with better-auth mongodbAdapter
